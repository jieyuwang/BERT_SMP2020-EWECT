# 微博情感分析实验总结报告

## 项目概述

本项目基于BERT预训练模型实现微博文本的六分类情感分析，包含完整的数据处理、模型训练、批量预测和评估分析流程。实验在Mac 2019款i7 CPU环境下完成，验证了BERT在中文情感分析任务上的有效性。

## 实验环境

- **硬件环境**: Mac 2019款 Intel i7 CPU (无独立GPU)
- **软件环境**: Python 3.8, PyTorch, Transformers
- **模型**: BERT-base-chinese
- **训练时间**: 约6小时 (5个epoch)
- **推理时间**: 9万条数据约15-30分钟

1. **数据增强**: 对fear、surprise类别进行数据增强

3. **模型集成**: 结合多个预训练模型提升性能
4. **后处理优化**: 基于类别先验概率进行预测校准
5. **超参数调优**: 使用网格搜索或贝叶斯优化调整学习率、批次大小
6. **梯度累积**: 在内存受限环境下实现更大批次训练
7. **混合精度训练**: 使用FP16加速训练并减少内存占用

## 完整实验流程

### 第一阶段：数据处理 (`1_process_data.py`)
1. **数据读取**: 从Excel文件读取原始微博数据
2. **文本清洗**: 去除URL、标准化处理
3. **均衡采样**: 每类情感标签采样1000条
4. **数据划分**: 训练集80% | 验证集10% | 测试集10%
5. **可视化分析**: 生成类别分布和文本长度分布图
6. **格式转换**: 保存为JSON格式便于模型训练

### 第二阶段：模型训练 (`2_finetune_weibo.py`)
1. **模型初始化**: 加载BERT-base-chinese预训练模型
2. **数据加载**: 构建WeiboDataset类，支持批量处理
3. **训练配置**: 设置优化器、学习率调度器、监控工具
4. **训练循环**: 5个epoch，每轮验证并保存最优模型
5. **过程监控**: TensorBoard记录、日志文件、可视化曲线
6. **模型保存**: 基于验证F1分数自动保存最优权重

### 第三阶段：批量预测 (`3_predict_and_save.py`)
1. **模型加载**: 加载预训练模型和微调权重
2. **数据分块**: 将9万条数据分块处理，避免内存溢出
3. **多进程并行**: 4个进程并行推理，支持GPU加速
